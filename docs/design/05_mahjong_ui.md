## 対局中キャラクター顔表示（後半実装予定）

対局中、画面の4隅に各プレイヤーの顔アイコンを表示する。  
点数状況に応じて表情が自動で変化する。

```
┌─────────────────────────────┐
│  [健太顔]        [じいさん顔]  │
│                              │
│       麻雀卓（牌）            │
│                              │
│  [松さん顔]      [美咲顔←自分]  │
└─────────────────────────────┘
```

### 表情パターン（案）

| 状態 | 表情 |
|---|---|
| 通常 | 普通顔 |
| 点数+（優勢） | 笑顔・余裕の表情 |
| 点数-（劣勢） | 焦り・困り顔 |
| リーチ宣言時 | 集中・鋭い表情 |
| 上がり | 喜び・ガッツポーズ |
| 振り込み | ショック・落ち込み |

> 詳細は後半フェーズで設計予定
