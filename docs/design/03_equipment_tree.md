## フェーズ解放条件（案）

| Phase | 解放条件 |
|---|---|
| Phase 1 → Phase 2 | Phase 1 全設備購入 OR 指定設備購入後に黒川イベント発生 |
| Phase 2 → Phase 3 | Phase 2 全設備購入 OR 大会開催イベントクリア |
| Phase 3 → Phase 4 | メディア取材イベントクリア |

> ※ 正確な解放条件はストーリー設計書（01_game_overview.md）と合わせて確定する

## ビル成長のビジュアル設計方針

- **ベース画像 1枚** ＋ **Phase別レイヤー（透過PNG）** を重ねる方式
- Phase 4 で隣店舗買収時に画面がズームアウトし、商店街全体が見える
- 設備を買うたびに店内・外観に変化が現れる（アニメーション演出）
- 詳細 → `docs/design/` に画像仕様を別途まとめる（image_spec参照）
