# 02 点・両の経済設計

> 雀荘物語における「両（りょう）」の設計思想と収入源

---

## 1. 基本思想

```
麻雀の得点（点数）
    ↓ 変換
三元楼ポイント ＝ 両（りょう）
    ↓ 使用
設備投資 → 店舗成長
```

**「現金」という概念を持ち込まない。**  
麻雀で勝って得た点数がそのまま店の資金になる仕組みで、  
三元楼ポイント制度規約（→ 01_game_overview.md）によりゲームが成立する。

---

## 2. 収入の二本柱

### 柱①　対局収入（メイン）

| 項目 | 内容 |
|---|---|
| 収入タイミング | 東風戦または半荘1セット終了時 |
| 収入の目安 | 平均 2,000両 / セット |
| 変動要因 | 順位・役の大きさ・ドラの数 |
| 備考 | ゲームの根幹。麻雀を打てば必ず収入が発生 |

### 柱②　探索・会話収入（サブ）

| 項目 | 内容 |
|---|---|
| 収入タイミング | セット内でいつでも（探索・会話ごとに即時） |
| 期待収入目安 | 350〜750両 / セット（全部試した場合） |
| 対局収入比 | 対局1回分の約1/4〜1/3程度 |
| リセットタイミング | 東風戦または半荘1セット終了時（対局収入と同期） |
| 備考 | やらないよりはやる程度の旨味。強制ではない |

> 詳細は → 04_explore_talk_design.md

## 3. 両の使途

| 使途 | 内容 |
|---|---|
| 設備投資 | 店舗強化・Phase進行の唯一の手段 |
| それ以外 | **なし**（換金・他用途は規約で永久禁止） |

---

## 5. バランス設計の考え方

- Phase 1 の全設備合計コスト：約 **6,300両**
- Phase 1 での1セット平均収入：約 **2,000〜3,000両**
- → Phase 1 クリアまで **3〜5セット**程度

プレイヤーに「もう1局打てばあの設備が買える」という  
**次の目標が常に見えている**状態を維持することが重要。
