# 06 チュートリアル設計書（初心者モード）

## 雀荘物語 チュートリアル設計書 v1.0

### 作成日
2026年6月

---

## 1. 設計方針

### 基本思想
**「押しつけない・でも困ったらいつでも戻れる」**

* **初心者モードは任意**: 強制せず、プレイヤーが選択できるようにします。
* **即座に非表示**: 全ての説明はタップ1つで即座に消去可能。
* **熟練者への配慮**: すでにルールを知っている熟練者には一切表示されません。
* **ステップ式解説**: 役の説明は「初めて成立したタイミング」に個別で出し、一度にすべてを見せないようにします。
* **ストーリー連動**: じいさん（黒川）が教えるという設計で、世界観およびキャラクター間のストーリーと完全に連動させます。

## 2. 初心者モードの ON/OFF

### 初回起動時
ゲーム開始時に選択肢を表示します。

> **「初心者モードで始めますか？」**
> 
> * **▶ はい**（じいさんが教えてくれます）
> * **▶ いいえ**（すでに麻雀を知っています）

* **「いいえ」を選んだ場合**: チュートリアルは完全に非表示になります（設定からいつでもONに変更可能）。
* **「はい」を選んだ場合**: 初心者モードON。じいさんが対局の流れに沿ってルールや操作を解説します。

### 設定からの切り替え
設定画面内に **「三元楼の教科書」** メニューを設け、以下の切り替えを可能にします。

| 設定項目 | 内容 |
| :--- | :--- |
| **初心者モード ON/OFF** | ヒント吹き出しの表示・非表示の切り替え |
| **三元楼の教科書** | 役一覧・点数表などの常設リファレンス |
| **既読ヒントを再表示** | 一度非表示にしたヒントを再度表示する |

* **ON → OFF に切り替えた時の会話劇**:
  * **じいさん**: 「もう教えんでいいか。一人前じゃな」
  * **美咲**: 「（嬉しいけど複雑）」
* **OFF → ON に戻した時の会話劇**:
  * **じいさん**: 「また頼ってきたか。……まあよい」
  * **美咲**: 「ちょっと優しい」

## 3. 学習ステップ詳細（7段階）

### STEP 1：牌の種類を覚える（対局前・初回のみ）
* **タイミング**: 初回対局開始前に自動表示。
* **内容**: 萬子（マンズ）・筒子（ピンズ）・索子（ソーズ）・字牌の4種類をイラスト（牌アセット画像）付きで表示。
* **スキップ**: 「わかった」ボタンで即スキップ。
* **会話劇**:
  * **じいさん**: 「牌には魂がある。……とまあ、そういうことにしておけ」
  * **美咲**: 「説明になってないです」

### STEP 2：手牌と捨て牌を知る（初回ツモ時）
* **タイミング**: 初めて自分のツモ番が来た瞬間。
* **内容**: 手牌エリアをハイライトし「これがあなたの手牌です」と表示。捨て牌エリア（河）を矢印で指示。
* **スキップ**: 吹き出しをタップすることで即時に消去。
* **会話劇**:
  * **じいさん**: 「いらない牌を捨てろ。人生と同じじゃ」
  * **美咲**: 「深いのか浅いのかわからない」

### STEP 3：リーチを覚える（初回テンパイ時）
* **タイミング**: プレイヤーの手牌が初めて「聴牌（テンパイ）」になった瞬間。
* **内容**: 「リーチできます！」のポップアップを表示し、リーチ宣言用のアクションボタンをハイライト。
* **スキップ**: 吹き出しをタップで即時に消去。
* **ヒントUIイメージ**:
  ```
  ┌────────────────────────────────────┐
  │ じいさんのヒント                    │
  │                                    │
  │ テンパイです！あと1枚で上がれます。  │
  │ 「リーチ」を宣言すると点数が上がり  │
  │ ますが、手牌を変えられなくなります。 │
  │                                    │
  │ じいさん「覚悟を決めろ。            │
  │          宣言は一度きりじゃ」       │
  │                                    │
  │ [リーチする]  [ダマで待つ]  [消す]  │
  └────────────────────────────────────┘
  ```
* **会話劇**:
  * **じいさん**: 「リーチとは宣言じゃ。『もう変えない』という覚悟」
  * **美咲**: 「（健太に聞かせたい言葉だ）」

### STEP 4：ツモ・ロンを覚える（初回上がり可能時）
* **タイミング**: 初めて「ツモ」または「ロン」の和了（あがり）権利が発生した瞬間。
* **内容**: 「ツモ」「ロン」ボタンをハイライトし、獲得方法の違いを説明。
* **スキップ**: 吹き出しをタップで即時に消去。
* **操作説明の対比**:
  * **ツモ**: 自分で引いた牌で上がる。全員から点数（親・子に応じた割り振り）をもらう。
  * **ロン**: 相手が捨てた牌で上がる。その牌を放銃した相手から点数を直撃（全額）もらう。
* **会話劇**:
  * **じいさん**: 「ツモは自力、ロンは相手の失敗を利用する。どちらも正道じゃ」
  * **美咲**: 「経営にも通じる気がする……」
  * **じいさん**: 「（ニヤリ）」

### STEP 5：役を覚える（初回成立時・順次）
* **タイミング**: 対局終局後の結果表示時、各役が初めて成立した瞬間にその役を個別解説。
* **内容**: 役名・翻数・簡単な成立条件・じいさんのひとことをカード（ボトムシート）で表示。
* **スキップ**: カードをタップで即消去。「三元楼の教科書に保存」ボタンを押すことで、後から見直しが可能。
* **役成立通知カード（UIイメージ）**:
  ```
  ┌──────────────────────────────┐
  │ タンヤオ 達成！  [はじめて]   │
  │                              │
  │ 2〜8の数牌だけで揃える役。   │
  │ 字牌を使わないシンプルな手。 │
  │ +1翻　得点UP                 │
  │                              │
  │ じいさん「2〜8だけ。潔い手じゃ」│
  │                              │
  │ [教科書に保存]  [閉じる]      │
  └──────────────────────────────┘
  ```
* **主要役の解説セリフ一覧**:
  | 役名 | 解説タイミング | じいさんのひとこと |
  | :--- | :--- | :--- |
  | **タンヤオ** | 初回成立時 | 「2〜8だけ。潔い手じゃ」 |
  | **リーチ** | 初回宣言後成立時 | 「宣言した通りに上がる。武士の一言じゃ」 |
  | **ピンフ** | 初回成立時 | 「美しい。教科書のような手じゃ」 |
  | **役牌** | 初回成立時 | 「字牌を大切にせよ。じいさんへの敬意じゃ」 |
  | **一発** | 初回成立時 | 「運も実力のうちじゃ」 |
  | **イーペーコー** | 初回成立時 | 「同じ並びが二つ。几帳面な手じゃな」 |
  | **三色同順** | 初回成立時 | 「3種類の牌を揃える。贅沢な手じゃ」 |
  | **一気通貫** | 初回成立時 | 「1から9まで。筋が通っておる」 |
  | **チャンタ** | 初回成立時 | 「端っこばかり集める。偏屈な手じゃ」 |
  | **七対子** | 初回成立時 | 「ペアを7つ。孤独な手じゃが美しい」 |
  | **国士無双** | 初回成立時 | 「……田所先生が見たら泣いて喜ぶ」 |
  | **四暗刻** | 初回成立時 | 「わしも生涯で1回しか出しとらん」 |
  | **役満全般** | 初回達成時 | 「田所先生も生涯で2回しか出なんだ」 |

### STEP 6：点数計算を覚える（対局終了後・3局目以降）
* **タイミング**: 3局目以降の終局（ラウンド終了）時の点数表示画面。
* **理由**: 最初の2局はテンポを最優先。獲得した「両（ゲーム内通貨）」のみを表示してテンポよく進めます。
* **内容**: 符・翻・点数の掛け合わせ関係をシンプルに図示。
* **点数説明UIイメージ**:
  ```
  今回の点数の計算式
  ─────────────────
  タンヤオ（1翻）× 40符
  → 子のロン：2,600点 → 2,600両
  ─────────────────
  翻が増えると点が増えます。
  符は手の形で変わります。
  ```
* **会話劇**:
  * **じいさん**: 「符と翻を掛け合わせると点が出る。詳しくは……美咲が自分で覚えろ」
  * **美咲**: 「投げた！？」
  * **じいさん**: 「教えすぎると覚えん。経営学部なら計算くらいできるじゃろ」

### STEP 7：三元楼の教科書（常設リファレンス）
* **場所**: 設定 → 「三元楼の教科書」からいつでも閲覧可能。
* **内容**: チュートリアルの進行状況とは独立して常設される包括的なリファレンス。
* **収録内容**:
  * **牌の種類**: 萬子・筒子・索子・字牌の一覧。
  * **基本ルール**: 手牌・捨て牌・ツモ・ロン・リーチの説明。
  * **役一覧**: 全役の翻数、条件、解説（ゲーム内で一度でも達成した役には「習得済み」マークが付与される）。
  * **点数表**: 符×翻の得点早見表。
  * **用語集**: ゲーム内のコメディ調テキストを交えた麻雀用語の解説。
* **会話劇**:
  * **じいさん**: 「わしが40年かけて覚えたことが一覧で見られる。……複雑な気持ちじゃ」
  * **美咲**: 「ありがとうございます（小声）」

## 4. ヒントUIの仕様

### 吹き出しヒント（対局中）
* **表示位置**: 関連する操作ボタン（「立直」「ポン」「チー」など）の近傍。
* **表示時間**: 自動で消えず、プレイヤーがタップするまで表示を維持。
* **消し方**: 吹き出し自体をタップするか、「ヒントを消す」ボタンを押す。
* **再表示**: 設定画面の「既読ヒントを再表示」ボタンでリセット可能。

### 役成立通知カード
* **表示タイミング**: 結果画面表示時。対局中に割り込んで演出を止めない仕様。
* **表示位置**: 画面下部からスライドアップしてくるボトムシート形式。
* **消し方**: カード自体をタップするか、「閉じる」ボタンを押す。
* **保存**: 「三元楼の教科書に保存」ボタンを押すことで、のちに教科書メニューから再確認可能。

### 点数説明（終局後）
* **表示タイミング**: リザルト結果表示画面の下部。
* **表示量**: 初回のみ詳細な計算構造を表示し、2回目以降は「簡易表示」へ切り替え。「詳しく見る」で三元楼の教科書内の「点数表」へジャンプします。

## 6. 世界展開への対応
この初心者向けチュートリアルは、単なるルール説明にとどまらず、ゲームの「文化翻訳（カルチャライズ）」要素として機能させます。

* **じいさんが教える設計**: 師匠と弟子のユニークな掛け合い（Master-Apprentice relationship）は、文化圏を問わず広く共感されやすい構成です。
* **コメディテキストの導入**: ルール理解のハードルを下げると同時に、キャラクター（じいさん、美咲）に対するプレイヤーの愛着を形成します。
* **「三元楼の教科書」という呼称**: 日本のレトロな雀荘らしさ・世界観を損なわずにそのまま世界にアピールします。
* **強制しない設計の採用**: アジア圏などのすでに麻雀ルールに精通しているプレイヤーに対し、不必要な解説をスキップさせてすぐにゲームの本質をプレイさせることができます。
