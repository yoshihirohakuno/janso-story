## 3. ゲームの核心設定

### 三元楼ポイント制度
黒川が昭和53年に顧問弁護士・田所先生と作った謎の規約。

> **三元楼ポイント制度規約**
>
> * **第1条**　三元楼ポイントは現金ではない
> * **第2条**　三元楼ポイントは店舗設備の改善にのみ使用できる
> * **第3条**　換金は永久に禁止とする
> * **第4条**　以上の理由により、これは賭けではない
> * **第5条**　田所先生も「たぶん大丈夫」と言っていた

→ 麻雀の得点 ＝ 三元楼ポイント ＝ 設備投資資金（両）　この一本の軸でゲームが成立する。

### 通貨設計（二層構造）

| レイヤー | 名称 | 役割 | リセット |
| :--- | :--- | :--- | :--- |
| **麻雀層** | 点（てん） | 符・翻で計算される対局スコア | 対局ごとにリセット |
| **経営層** | 両（りょう） | 雀荘設備への投資通貨 | 使うまで残る |

* **変換レート**: 1点 = 1両（対局終了時に自動変換）

## 4. オープニングシーン（決定稿 v2）

ドラクエ方式を採用。「経営学部＝勇者」のメタファーで黒川がテンションを上げる。  
「はい／いいえ」で「いいえ」を選ぶと黒川が同じ質問を繰り返す（無限ループ）。  
ルール説明（三元楼ポイント制度）は対局の後に置き、まず1局打たせてから入る構成。

### シーン1：入店（自動移動・操作不可）
> 薄暗い雀荘「三元楼」。健太に連れられ、美咲は初めて足を踏み入れた。

> [!NOTE]
> **演出指示**
> * 入店 → プレイヤー操作不可（カットシーン）。
> * 美咲・健太のキャラクターが自動で歩行し、カウンター奥の黒川の元へ移動。
> * 到着と同時にシーン2の会話が自動的に開始する。
> * 店内を自由に歩けるのはシーン10（ゲームスタート後）から。この時点ではプレイヤーに移動の選択権を与えず、黒川の元へ一直線に進める。

**健太**：「おーい黒川さん！　彼女連れてきました！」

### シーン2：黒川登場
> カウンターの奥から、黒川がゆっくり顔を上げる。

**黒川**：「ほう。彼女さん……初めてかね？」  
**美咲**：「あ、はい。田中美咲です。よろしくお願いします。」

### シーン3：自己紹介から経営学部判明
**黒川**：「田中さんは、お仕事は……いや、学生さんかね？」  
**美咲**：「大学2年です。」  
**健太**：「経営学部なんですよ、美咲！」

### シーン4：黒川の覚醒（経営学部＝勇者メタファー）
> 黒川の目の色が、わずかに変わる。（ドラクエの「勇者発見」効果音のイメージ）

**黒川**：「……！！　経営学部とな？？」  
**美咲**：「え、はい……それが何か……？」  
**黒川**：「おお……おお！　ついに現れたか……！」  
**健太**：「（黒川さん、テンション高くなった？）」  
**黒川**：「長きにわたり、わしはこの店を立て直せる者を待っておった。」  
**黒川**：「経営学部……まさに、伝説に語られし者ぞ。」  
**美咲**：「伝説は大げさです！　ただの2年生です！」

### シーン5：譲渡を仕掛ける
**黒川**：「田中よ。単刀直入に聞こう。」  
**黒川**：「この店、譲り受けてみる気はないかね？」  
**健太**：「（リーチ……あ、まだ打ってない）」

* **選択肢①（ドラクエ方式）**
  * **▶ ……考えてみます**
  * **▶ いえ、無理です** → 黒川：「そうか。……では、もう一度聞こう。経営学部の者よ、この店を継いでくれぬか？」（呼び方が「経営学部の者」に変化／無限ループ）

### シーン6：いきなり対局へ（事前ルール説明なし）
> ここでは「賭けではない」等のルール説明は一切行わない。まず打たせる。

**黒川**：「よし。では、その力——まことに伝説の者か——」  
**黒川**：「わしと一局、見せてみよ。」  
**美咲**：「え、私何も知らな——」  
**健太**：「大丈夫だって！　黒川さん教えてくれるから！」

> 美咲が席につく。黒川が静かに牌を積み始める。

### シーン7：対局開始演出（戦闘導入演出）
> 画面暗転 →「対局開始」のロゴ表示 → 麻雀卓へズームイン。
> ドラクエの戦闘画面突入を意識した、短い暗転＋ロゴ演出を挟む。

### シーン8：対局結果（勝敗分岐・どちらも前向き）
* **【勝った場合】**
  > 対局を終え、黒川が目を見開く。
  * **黒川**：「……勝ったか。初めてで、勝ったか。」
  * **美咲**：「よくわからないまま勝っちゃいました……」
  * **黒川**：「うむ。これは思った以上に……うむ。」
  * **美咲**：「（なんか、ちょっと……面白いかも）」
* **【負けた場合】**
  > 対局を終え、黒川が小さくうなずく。
  * **黒川**：「負けたな。じゃが——筋は、悪くない。」
  * **美咲**：「負けたのに褒められると、ちょっと悔しいです……」
  * **黒川**：「その悔しさが、ちょうどよい。」
  * **美咲**：「（次は勝ちたい、って思ってる私……？）」

> 勝敗にかかわらず、美咲が前向きになった状態でシーン9へ進む。

### シーン9：ルール説明（対局後・初めて提示）
**黒川**：「よし。少しはやる気になったようじゃな。ならば——この店のルールを教えておこう。」

> 三元楼ポイント制度規約の提示（カード表示）。  
> 麻雀で得た点数が、そのまま店を直す「両」になる。ただし——これは賭け麻雀ではないぞい。

**美咲**：「いや、賭けと何が違うんですか！？」  
**黒川**：「細かいことを気にするな。経営学部の悪いクセじゃ。」

* **選択肢②（ドラクエ方式）**
  * **▶ 引き受ける**
  * **▶ 断る** → 黒川：「そうか。……では、もう一度聞こう。」（無限ループ）

### シーン10：ゲームスタート
**黒川**：「よい。今日からこの店は、おぬしのものじゃ。」  
**美咲**：「（やる気が出てきた……これも経営学部の血か……？）」

> こうして美咲の、誰も頼んでいない雀荘経営がはじまった。  
> 初めて、店の中を自由に歩けるようになる。

> [!NOTE]
> **演出指示**
> * ここでカットシーンが終了し、プレイヤー操作が解放される。
> * シーン1の「自動移動のみ」と対比し、初めて美咲を自由に動かせる瞬間として演出する。

## 5. ゲームの二軸ループ

```
【麻雀パート】対局 → 得点を稼ぐ
        ↓ 得点 → 両（三元楼ポイント）に自動変換
【経営パート】両で設備投資
        ↓ 設備UP → 新イベント・新キャラ解放
【麻雀パート】へ戻る（ループ）
```

### 画面遷移
```
経営画面（メイン）
  └─ 対局ボタンタップ
      └─ 麻雀画面（全画面）
          └─ 対局終了
              └─ 結果画面「+3,200両獲得！」
                  └─ 経営画面（両が増えている）
```

## 6. フェーズ別ストーリー詳細

### Phase 1　ボロ雀荘（開始〜6,300両）
**店の状態:** 1Fのみ・4卓・電球切れかけ

美咲がツッコむ→黒川が規約の第1〜5条を読み上げる→美咲が第5条で絶句する。

#### Ph.1 中盤イベント：ヤスおじさんの統計データ回
美咲が経営学部らしく「データで考えよう」と、ヤスおじさんの過去の対局成績を集計。
> **美咲**：「ヤスさん……勝率50.3%ですよ？　ほぼ平均です」

> **美咲**：「下がってないです！！」

#### Ph.1 終盤イベント：女子大生トリオのSNS初投稿

#### Ph.2 終盤イベント：吉田さんへの疑惑

## 9. アセット設計方針

* ビルは1枚のベース画像にレイヤーを重ねる方式
* フェーズが上がるごとにパーツ（電球・卓・看板・階層など）が追加される
* 背景を大量に作る必要がなく、開発コストを最小化できる
* Phase 4で隣店舗買収時に画面がズームアウトし、商店街全体が見えるようになる
