## 3. ゲームの核心設定

### 三元楼ポイント制度

じいさんが昭和53年に顧問弁護士・田所先生と作った謎の規約。

**三元楼ポイント制度規約**

> 第1条　三元楼ポイントは現金ではない  
> 第2条　三元楼ポイントは店舗設備の改善にのみ使用できる  
> 第3条　換金は永久に禁止とする  
> 第4条　以上の理由により、これは賭けではない  
> 第5条　田所先生も「たぶん大丈夫」と言っていた  

→ 麻雀の得点 ＝ 三元楼ポイント ＝ 設備投資資金　この一本の軸でゲームが成立する。

## 4. オープニングシーン（決定稿）

ドラクエ方式を採用。「はい／いいえ」で必ず「はい」を選ばなければ先に進まない。
「いいえ」を選ぶとじいさんが同じ質問を繰り返す。

### シーン1：入店
> 薄暗い雀荘「三元楼」。健太に連れられ、美咲は初めて足を踏み入れた。

**健太**「ここ最高だろ。俺のホームグラウンド。」  
**美咲**「……デートって言ってたよね？」

### シーン2：じいさん登場
> カウンターの奥から、じいさんが現れる。

**じいさん**「ふむ。おぬし——経営学部じゃな？」

**選択肢①（ドラクエ方式）**
- ▶ はい
- ▶ いいえ（→じいさんが同じ質問を繰り返す・無限ループ）

### シーン3：譲渡宣言
**じいさん**「よし。この店を、おぬしに譲ろう。」  
**美咲**「え？」  
**じいさん**「麻雀を打って得た得点で、この店を立て直してほしい。」  
**じいさん**「これは賭け麻雀ではないぞい。」

### シーン4：健太への怒り
**美咲**「なんで私が経営学部だとわかったんですか？」  
**じいさん**「健太が言っておった。」  
**美咲**「健太くん！！」  
**健太**「（リーチ！）」  
**美咲**「聞いてない！！」

**選択肢②（ドラクエ方式）**
- ▶ 引き受ける
- ▶ 断る（→じいさんが同じ質問を繰り返す・無限ループ）

### シーン5：ゲームスタート
**じいさん**「よし。話が早い。エプロンじゃ。」  
**美咲**「え、もうですか！？」  
**じいさん**「経営学部は、細かいことを気にしすぎる。」  
**美咲**「これは細かくない、これは普通の反応です！！」

> こうして美咲の、誰も頼んでいない雀荘経営がはじまった。

## 5. ゲームの二軸ループ

```
【麻雀パート】対局 → 得点を稼ぐ
        ↓ 得点 → 三元楼ポイントに変換
【経営パート】ポイントで設備投資
        ↓ 設備UP → 新イベント・新キャラ解放
【麻雀パート】へ戻る（ループ）
```

### 画面遷移

```
経営画面（メイン）
  └─ 対局ボタンタップ
      └─ 麻雀画面（全画面）
          └─ 対局終了
              └─ 結果画面「+3,200ポイント獲得！」
                  └─ 経営画面（ポイントが増えている）
```

## 9. アセット設計方針

- ビルは1枚のベース画像にレイヤーを重ねる方式
- フェーズが上がるごとにパーツ（電球・卓・看板・階層など）が追加される
- 背景を大量に作る必要がなく、開発コストを最小化できる
- Phase 4で隣店舗買収時に画面がズームアウトし、商店街全体が見えるようになる
